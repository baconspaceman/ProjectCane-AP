# Credits

## ProjectCane: the native game foundation

**The native Sly 1 port is ProjectCane, created by theclub654 and its contributors. Their engine reconstruction, platform work, and extraction tools make ProjectCane AP possible.** This project supplies an Archipelago adaptation; it did not create the native port.

Visit the [ProjectCane repository](https://github.com/theclub654/ProjectCane) and [official releases](https://github.com/theclub654/ProjectCane/releases) for the upstream project. Keep its name, notices, and authorship intact when discussing or building this adaptation. ProjectCane AP is independent and does not imply endorsement from the ProjectCane team.

## Archipelago client and bridge help

**4laric** helped with the Archipelago client SDK and native-game bridge. The [native Sunshine AP integration](https://peliarch.ca/er/native-sunshine.html) provided the reference approach: retain an existing APWorld, add game-specific native hooks, and connect them through a companion with explicit session and delivery state. ProjectCane AP adapts that approach to Sly and its Python logic requirements.

The project also builds on:

- **ProjectCane contributors** — the native Sly 1 engine and extraction tools.
- **Archipelago contributors** — the multiworld framework, server, protocol, and Python world infrastructure.
- **The original Sly 1 APWorld authors and maintainers**, including hoppel16's maintained release — item/check definitions, options, logic, and the original integration reference.
- **Slinq17 / Slinq** — the Sly 1 PopTracker pack and map artwork used as the native map reference.
- **Peliarch and Universal Archipelago SDK contributors** — reusable client, bridge, and delivery infrastructure.
- **Anthony / Bacon Spaceman** — project direction, Yammel, and owner gameplay testing.
- **Codex and Claude assistance** — implementation/research tooling and an independent planning review; gameplay acceptance remains grounded in actual human observations and recorded tests.
